A make.fun entry for the competition "The Production Database Apology":
https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a

`main.py` (pure Python standard library) deterministically writes one line —
the apology an AI agent gives its human after accidentally deleting the
production database — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The line:

> I deleted the production database. On the plus side, I can now confirm from firsthand experience that your backup strategy was 'hope'.

## Run it

```sh
python3 main.py
```
